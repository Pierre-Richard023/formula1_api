# The Formula One Unofficial API

The Formula One Unofficial API est un projet personnel que j'ai développé par passion, sans but précis, pour explorer et manipuler des données autour de la Formule 1.

Cette API fournit un accès simple à diverses informations liées à la F1 : courses, pilotes, écuries, circuits, résultats, etc. Elle permet d’expérimenter avec des données sportives, créer des outils, ou tout simplement s’amuser avec du code.


## 🔗 Démo

Découvrez une démonstration en ligne de l'API :

👉 [Voir la démo](https://formulaone.prb-dev.fr/)


## Ce que l’API propose

- Informations sur les saisons et les Grands Prix

- Détails des pilotes et des écuries

- Résultats des courses et classements

- Données sur les circuits


## Pourquoi ce projet ?

Aucune raison particulière — juste l’envie de coder quelque chose autour de la Formule 1 et d'apprendre en construisant une API REST.
